# 🧳 旅行小行囊 · 出行清单

一个温馨可爱的旅行物品清单网页：多行程管理、丰富的分类预设与场景模板，数据保存在浏览器本地，无需登录、无需联网使用。

**在线使用**：<https://owen88ob.github.io/travel-checklist/>

## ✨ 功能

- **多行程管理** —— 创建任意多个行程（名称 / 图标 / 目的地 / 出发日期），随时切换，还带出发倒计时
- **六大分类 · 124 件预设物品** —— 衣物、数码、洗漱用品、证件财务、健康药品、食品杂物，也可在分类卡片里直接输入自定义物品
- **自定义物品收藏到物品库** —— 在物品库的分类里随时添加自己的常用物品（带 ★ 标记），跨行程重复使用，也可移除
- **分享行程** —— 一键生成含完整清单的分享链接，朋友打开即可预览并导入为自己的行程；也可复制文字清单或唤起手机系统分享
- **六套场景模板一键填充** —— 通用出行 / 海边度假 / 冬季出行 / 商务出差 / 户外露营 / 亲子出游
- **物品库多选批量添加** —— 自动标记清单里已有的物品，不会重复添加
- **进度环与庆祝动画** —— 实时显示收拾进度，全部打包完成时撒彩带庆祝 🎉
- **清单操作** —— 勾选完成、清空已勾选、一键重置（再次出发）、删除条目
- **数据本地保存** —— 所有数据仅存于浏览器 localStorage，刷新不丢失，保护隐私

## 🎨 界面

- 奶油底色 + 蜜桃粉马卡龙配色，圆润可爱的中文字体
- 背景漂浮的云朵、飞过的小飞机、气球与柔和光斑
- 条目渐入、勾选弹性动画、进度数字滚动、按钮微交互等丰富动效
- 完整适配桌面端与移动端，支持 `prefers-reduced-motion`

## 🚀 使用

纯静态页面（HTML + CSS + 原生 JavaScript，零依赖），克隆后直接打开 `index.html` 即可，无需构建：

```bash
git clone https://github.com/owen88ob/travel-checklist.git
```

或直接访问在线链接使用。

## 📁 结构

```
travel-checklist/
├── index.html   # 页面结构
├── style.css    # 样式与动画
└── app.js       # 数据模型 / 预设库 / 渲染与交互
```
